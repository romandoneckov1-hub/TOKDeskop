# TOKDesktop GitHub Pages

1. Create a GitHub repository, for example `TOKDesktop`.
2. Upload `index.html`, `privacy.html`, and `terms.html`.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Save and wait for GitHub Pages to publish.
6. Your URL will look like `https://YOUR-USERNAME.github.io/TOKDesktop/`.

Use that public HTTPS address as the Web/Desktop URL in the TikTok Developer Portal.
